# BlinkIT-Grocery-Sales-Dashboard-
Analyze overall grocery sales performance.

## Project Overview

This project is an interactive Power BI dashboard built to analyze BlinkIT grocery sales performance. The dashboard provides a complete view of sales, orders, ratings, outlet performance, item categories, and outlet establishment trends.
The goal of this project is to transform raw grocery sales data into actionable business insights using Excel, Power Query, DAX, and Power BI.

## Project Objectives 

- Analyze overall grocery sales performance.
- Track total sales, average sales, total orders, and customer ratings.
- Identify top-performing item categories.
- Compare sales across outlet locations and outlet sizes.
- Understand the impact of outlet establishment years on sales trends.
- Build a dynamic and interactive dashboard for business decision-making.

## Business Problem

BlinkIT generates a large amount of grocery sales data from different outlet locations and item categories. Analyzing this data in raw Excel format makes it difficult to:

- What is the total grocery sales revenue?
- Which item category generates the highest sales?
- Which outlet tier contributes the most revenue?
- How do small, medium, and high outlet sizes perform?
- What is the total number of orders placed?
- How do sales change based on outlet establishment year?
- Which outlet type has the highest sales contribution?
- what is the average customer rating across outlets?
- How does fat content affect sales distribution?
- Which outlet segments require improvement for better performance?
- Generate quick business insights for management.

This dashboard solves the problem by providing a centralized, interactive, and visual reporting solution.

## Tools Used

- Microsoft Power BI – Dashboard development
- Power Query – Data cleaning and transformation
- DAX (Data Analysis Expressions) – KPI calculations and measures
- Microsoft Excel – Source dataset preparation
- Data Modeling – Relationship creation and structured reporting

## Dashboard Development Process

1️. Data Collection
- Imported the Excel grocery sales dataset into Power BI.

2️. Data Cleaning (Power Query)
- Removed duplicate records
- Handled missing values
- Corrected data types
- Standardized outlet and item category names
- Formatted date and year columns

3️. Data Modeling
- Created relationships between tables
- Organized the dataset into a structured reporting model

4️. DAX Calculations

Created measures for:

- Total Sales
- Average Sales
- Total Orders
- Average Rating
- Outlet-wise Sales Contribution
- Category-wise Sales Analysis

5️. Dashboard Design

- KPI Cards
- Line & Area Charts
- Donut Charts
- Bar Charts
- Funnel-style outlet comparison
- Interactive slicers for dynamic filtering

## Dashboard Features
-  1.20M Total Sales KPI
-  9K Total Orders Tracking
-  Average Sales & Rating Metrics
-  Outlet Establishment Trend Analysis
-  Fat Content Distribution
-  Item Type Sales Comparison
-  Outlet Size Performance Analysis
-  Sales by Outlet Location (Tier 1, Tier 2, Tier 3)
-  Outlet Type Performance Table
-  Interactive Filters for Location, Year, and Item Type
